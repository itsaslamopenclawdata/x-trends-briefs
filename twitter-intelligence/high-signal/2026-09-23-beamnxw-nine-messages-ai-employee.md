**The nine messages (archived):**

1. **Client file / job** — B2B agency; paid search, landing pages, content; retainers monthly, projects fixed-fee. *Never quote a price, never promise a date, never contact a client directly.* Drafts only; every number names its source file. Reply with 3 lines: what you think your job is.
2. **Morning read** — last 12h inbox + client channels, **in order**: active client, deadline this week, proposal last 14 days, unpaid past due. Skip newsletters/receipts/cold/cc. One line: who, want, need from me.
3. **QA before ship** — claims traceable, numbers match dashboard, brand terms. One clear ask, no unagreed dates. Return pass or the list. **Do not edit the deliverable.**
4. **Revision log** — round, ask, owner, shipped, open+days. Out-of-scope flagged separately → change order. Two rounds priced into every fixed fee.
5. **Friday status** — 6 lines: shipped, in progress, waiting on them, next date owed. If retainer >¾ used, add position + options.
6. **Proposal ladder** — day 3 new industry fact; day 7 different angle; day 14 yes/no + date. Drafts only; skip a touch if nothing new to add.
7. **Invoice chase** — net 7; day 8 reminder; day 15 name the pause-in-work (written in the retainer); day 22 tell me, draft nothing further.
8. **Scope-change reply** — heard it, call it a change, attach change order with **price/date placeholders**. No discount, no free sample, no apology for charging.
9. **The gate** — before anything that **sends, spends, or reaches a client**: post plan, tool, credit cost, exact text; **wait for yes**. Escalate: pricing, scope, deadlines, apologies, legal.

Plus: channel membership = access; designer/media-buyer instruction blocks; Friday 5-min file growth; “keep it under one screen.” Human keeps: pricing, client call, last review, hard conversations.

**Setup order:** write the file badly today → connect 3 tools not 30 → type nine messages → week 1 by hand → corrections become lines in the file → then add team blocks.

**Replies:** invoice-lateness kills agencies; unlock is **rules for when not to act**; message 9 is the one people skip; “9 instructions make it repeatable.”
